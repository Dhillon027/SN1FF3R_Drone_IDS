Getting set up

  1. Start the simulator with one output for the IDS and one for the test tools: 
    sim_vehicle.py -v ArduCopter --console --map --out=udp:127.0.0.1:14560 --out=udp:127.0.0.1:14551
  2. Start this app on its own port: 
    sn1ff3r gui --connect udpin:127.0.0.1:14560
  3. Take off from the MAVProxy console: 
    mode guided
arm throttle
takeoff 20
GPS spoofing and the settings check use port 14551. Everything else is sent straight to the IDS on — and never reaches the autopilot.
